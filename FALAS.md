# Falas do Márcio

Roteiro de todas as falas do Márcio pescador para gravar no **ElevenLabs** (modelo v3, que entende as tags entre colchetes).

- **Roteiro (ElevenLabs):** cole exatamente esse texto. As tags (`[angry]`, `[whispering]`, `[drunken voice]`...) controlam a emoção.
- **Balão:** o que aparece no jogo; as tags somem e o cochicho vai entre parênteses.
- **Arquivo:** nome do áudio. Os áudios vão em `src/main/resources/assets/bauchefe/sounds/marcio/<arquivo>.ogg` (OGG Vorbis, **mono**).
- Se a voz pronunciar errado "hirozn" ou "giizanini", troque a grafia só no roteiro (o nome do arquivo continua igual).
- Os textos dos balões estão em `src/main/java/br/hirozn/bauchefe/Falas.java`; mudou lá, muda aqui também.

Total: **88 áudios**.
